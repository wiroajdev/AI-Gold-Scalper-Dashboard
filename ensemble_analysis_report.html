Feature Name คณิตศาสตร์ / วิธีคำนวณ มิติที่ต้องการวัด (Market Dimension) บทบาทในตลาดทองคำ

macd_diff MACD Line (EMA12 - EMA26) - Signal Line (EMA9) Trend Divergence & Acceleration บอกการกลับตัวของโมเมนตัมแนวโน้มก่อนที่ราคาเฉลี่ยระยะยาวจะเปลี่ยนทิศ
bb_pos (Close - LowerBB) / (UpperBB - LowerBB) Relative Range Position ตำแหน่งสัมพัทธ์ของราคาในกรอบ 2 Standard Deviations (0.0 = แนวรับ, 1.0 = แนวต้าน)

atr14 Rolling Mean ของ True Range (14 บาร์) Market Volatility Normalizer เป็นตัวหาร (Denominator) เพื่อปรับสเกลของโมเมนตัมและระยะห่างไม่ให้ลำเอียงตามราคา
ema_diff_atr (EMA9 - EMA21) / ATR14 Volatility-Adjusted Trend Gap ฟีเจอร์สำคัญ: วัดว่าระยะห่างเส้นค่าเฉลี่ยวิ่งฉีกออกห่างจากกันกี่เท่าของ ATR
candle_body (Close - Open) / (High - Low + ε) Price Action: Net Bull/Bear Pressure Price Action Metric: วัดขนาดเนื้อเทียนเทียบกับความยาวทั้งแท่ง (-1.0 ถึง +1.0)
upper_shadow (High - max(Close, Open)) / (High - Low + ε) Price Action: Selling Rejection Wick วัดความยาวไส้เทียนด้านบน เพื่อจับพฤติกรรม Reject แนวต้าน (Pinbar / Shooting Star)
lower_shadow (min(Close, Open) - Low) / (High - Low + ε) Price Action: Buying Rejection Wick วัดความยาวไส้เทียนด้านล่าง เพื่อจับพฤติกรรม Reject แนวรับ (Hammer / Spring)
mom_3 / mom_5 (Close - Close[n]) / ATR14 Short-Term Normalized Velocity ความเร็วในการเคลื่อนที่ของราคาใน 3 และ 5 แท่งล่าสุด ปรับตามความผันผวน
vol_ratio TickVolume / Volume.rolling(20).mean() Liquidity Burst & Volume Expansion วัดการกระชากของสภาพคล่อง ถ้า > 1.5 หมายถึงสถาบันหรือผู้เล่นใหญ่เริ่มเข้ามาร่วมวง

🤖 เจาะลึก 9 อัลกอริทึม (Model Architecture Deep Dive)

1. Random Forest Bagging Trees
ใช้อาร์เรย์ของ Decision Trees 40 ต้น (Max Depth 5) สร้างขึ้นจากการสุ่มแถวข้อมูล (Bootstrap) และสุ่ม Subset ของฟีเจอร์ เพื่อหาฉันทามติจากการโหวต
Parameters:
• n_estimators: 40
• max_depth: 5
• criteria: Gini Impurity
ข้อดี:
✓ ทนทานต่อ Noise สูงมาก
✓ จับความสัมพันธ์ Non-linear ได้ดี
✓ ไม่ Overfit กับ Spike สั้นๆ
ข้อด้อย:
✗ ปรับตัวช้าเมื่อเปลี่ยน Regime ทันที
✗ มีแนวโน้มโหวต HOLD บ่อยในตลาดเงียบ
2. Gradient Boosting Sequential Boosting
สร้าง Shallow Trees 35 ต้น (Max Depth 3) แบบอนุกรม โดยแต่ละต้นมุ่งลดทอน Residual Error ของต้นก่อนหน้าผ่านอัลกอริทึม Gradient Descent
Parameters:
• n_estimators: 35
• max_depth: 3
• learning_rate: 0.1
ข้อดี:
✓ แม่นยำสูงสุดในการหา Edge
✓ จับจุดกลับตัวระดับ Micro ได้ไว
✓ ให้น้ำหนักเคสที่ทำนายยาก
ข้อด้อย:
✗ ไวต่อ Outlier และ False Breakout
✗ เสี่ยง Overfit สูงหากตลาดไม่มีเทรนด์
3. Extra Trees Randomized Trees
Extremely Randomized Trees (35 ต้น, Depth 5) แตกต่างจาก Random Forest ตรงที่จุดแบ่งกิ่ง (Split Cutoffs) ถูกสุ่มเลือก 100% แทนที่จะหา Best Split
Parameters:

✓ ลด Variance ได้ยอดเยี่ยม

4. Support Vector (SVC) RBF Hyperplane
แปลงข้อมูลขึ้นสู่มิติไร้ขอบเขตผ่าน RBF Kernel เพื่อค้นหาระนาบแยก (Hyperplane) ที่มีระยะห่างจาก Support Vectors กว้างที่สุด
Parameters:
• kernel: 'rbf'
• C: 1.0 (Regularization)
• gamma: 'scale'
ข้อดี:
✓ ทรงพลังในพื้นที่หลายมิติ
✓ แข็งแกร่งต่อฟีเจอร์ที่ไม่เกี่ยวข้อง
✓ เส้นแบ่งมีความแน่นอนสูง
ข้อด้อย:
✗ อ่อนไหวต่อสเกลของราคา
✗ คำนวณช้าหากบาร์ข้อมูลมากเกินไป

ค้นหาแท่งเทียนในอดีต 7 แท่งที่มีค่า Technical Features 12 ตัวใกล้เคียงกับแท่งปัจจุบันมากที่สุด (Euclidean Distance) แล้วโหวตตามเสียงข้างมาก

ข้อด้อย:
